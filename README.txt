# TerpalKu Website Starter

## Cara menjalankan
1. Extract folder ZIP.
2. Buka folder `terpal-website` di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server untuk preview otomatis.

## Sebelum dipublikasikan
- Ganti tulisan "TerpalKu" dengan nama bisnis client.
- Ganti logo teks "T" dengan file logo client (lihat komentar di index.html atau minta bantuan untuk memasangnya).
- Ganti nomor `6281234567890` di `script.js` dengan nomor WhatsApp bisnis.
- Ganti foto contoh di `index.html` dan `style.css` dengan foto produk asli.
- Perbarui kategori, nama produk, deskripsi, dan spesifikasi berdasarkan data client.
- Cek ulang tampilan desktop dan mobile.

Website menggunakan HTML, CSS, dan JavaScript murni. Foto contoh memuat dari Unsplash dan membutuhkan koneksi internet.
